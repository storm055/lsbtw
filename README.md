# lsbtw

Uma reimplementação do `ls` em C, criada como projeto de estudo de programação de sistemas no Linux.

O projeto nasceu da ideia de reescrever uma ferramenta tradicional do Unix em C, explorando diretamente APIs POSIX e conceitos de baixo nível como diretórios, permissões, usuários, grupos, estruturas e argumentos de linha de comando.

Atualmente, o projeto está em desenvolvimento e serve principalmente como forma de aprofundar meus conhecimentos em C e programação no Linux.

## Objetivos

* Reimplementar funcionalidades básicas do `ls`
* Praticar C na prática
* Aprender mais sobre APIs POSIX
* Trabalhar com arquivos e diretórios
* Entender permissões e metadados
* Evitar abstrações desnecessárias e aprender como as ferramentas Unix funcionam por baixo
